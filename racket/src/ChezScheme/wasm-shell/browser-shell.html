Experimental Browser Shell

Racket CS on WASM

This page wraps the generated scheme-web.js runtime in an xterm.js terminal. It expects scheme-web.js, scheme-web.wasm, and scheme-web.data to be in the same directory, and must be served cross-origin isolated (COOP/COEP).

Interactive Terminal

The runtime runs in a dedicated Web Worker we spawn; input/output cross to this page through SharedArrayBuffer rings.

This shell loads xterm.js from cdnjs. Serve this directory with python3 serve.py (it sets the COOP/COEP headers SharedArrayBuffer needs); a plain static server without those headers will not start the runtime.

stdin/stdout are bridged via shared-memory rings: the page polls the output ring each frame and writes typed lines into the input ring, which the runtime worker blocks on with Atomics.wait (idle uses no CPU).

Line editing on the page: arrow keys (incl. history with ↑/↓), Home/End, Delete/Backspace, and the readline-style Ctrl-A/E/B/F/K/U/W/Y/L/P/N. The line goes to Racket only on Enter.
