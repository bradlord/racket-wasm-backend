This is not a terminal: it's a plain text-area editor on the page, paired with an output pane. The browser handles all editing (arrows, paste, undo, find). Racket only sees the expression once you submit it.

        
stdin/stdout are bridged via shared-memory rings: the page polls the output ring each frame and writes submitted text into the input ring, which the runtime worker blocks on with Atomics.wait (idle uses no CPU).

        
/home/web_user is mounted on IndexedDB. Persistence is explicit: click Save & Restart to flush any files you've written there. (We send (exit 0) on the input ring so the runtime exits cleanly; Module.onExit then runs FS.syncfs(false) while the worker's event loop is finally free. The REPL session is replaced by a fresh one on respawn — variables and definitions are lost, files survive.)
