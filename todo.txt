Overall Goal: The scripts in this repo should let me create custom Racket/WASM-based web applications, rather than just the IDE/web-repl and the node repl. Eventually, I should be able to point to a directory with HTML/JS/Racket and some configuration (preferably written in racket), and have it output a usable web page (including the WASM and .data files needed to run it.)

=== Progress (branch wasm-custom-apps; see build-wasm.md + ~/.claude/plans) ===
